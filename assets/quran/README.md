# Quran text attribution

Arabic text from quran-json 3.1.2 by Risan Bagja Pradana: https://github.com/risan/quran-json (npm: https://www.npmjs.com/package/quran-json/v/3.1.2). Distributed under CC BY-SA 4.0; see LICENSE.txt. Source package credits The Noble Quran Encyclopedia (https://quranenc.com/en/home) for the Uthmani Arabic text.

Arabic verse strings are unchanged. Only transliteration fields were omitted and chapters combined into one local JSON file. Reader spreads are UI groupings, not traditional Mushaf page numbers. No translation or audio is included.
